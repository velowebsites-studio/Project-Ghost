🚩 Practice Red Flag #1

Real MetaMask NEVER asks for your password via a website. You only enter your password into the browser extension itself.

🚩 Practice Red Flag #2

Check the URL. Does it say metamask.io? A fake site might have a slightly different URL like 'metamask.io' with a zero instead of an 'o'.

🚩 Practice Red Flag #3

This page only asks for a password. A real login might ask for your Secret Recovery Phrase, which is an even bigger red flag. NEVER enter your phrase on a website.
